# Data Analysis & BI Portfolio
This portfolio highlights end-to-end analytics work: cleaning messy data, building analytical models, and communicating findings through dashboards and notebooks.

## What this repo shows

- **Data cleaning & preprocessing** — standardizing records, handling missing values, and preparing data for analysis
- **Exploratory analysis** — profiling distributions, spotting trends, and identifying outliers
- **Business metrics** — sales performance, admissions, churn, complaints, and customer behavior
- **Modeling & predictions** — classification, regression, and recommendation examples where relevant
- **Visualization & storytelling** — charts and structured notebooks that lead to decisions

## Featured projects

| Project | Focus | Tools |
|---------|-------|-------|
| Coffee Sales Analysis | Retail analytics and time-based revenue patterns | Python, pandas, matplotlib |
| Hospital Analytics Pipeline | Admissions, LOS, cost trends, and payer analysis | Python, SQLite, pandas |

| Bike Rentals Analysis | Demand patterns and review-driven insights | Python, pandas |
| Customer Analytics | Churn, credit card behavior, and employee turnover | Python, pandas, scikit-learn |
| Grievance Analysis | Complaint themes and operational improvements | Python, pandas |

| Movie Recommendations | Collaborative filtering and recommendation design | Python, pandas |

## How to use this repo

1. Clone the repo.
2. Create and activate a virtual environment.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Open any notebook or script in the project folder of interest.
